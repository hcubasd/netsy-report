# NetSy literature review — v0.2.0

Title: **NetSy: A Network loads and emissions Synthesizer**. Publication line: `v0`.

Eight search strands organize evidence identification: six subject areas, data availability/representation/transferability, and MASS-GT reference discovery. Seven functional responsibilities organize the findings: study-area representation, goods demand, goods exchanges, logistics organization, vehicle activity, network loading and environmental assessment. Each functional section integrates academic approaches, their data requirements and the MASS-GT configuration. This is a many-to-many synthesis framework, not eight equivalent academic fields or eight software modules. NetSy implementation positioning remains deferred.

The structural revision retains the evidence cohort published as v0.1.0. The 18 November institutional pass supplied eleven relevant complete papers (two replacing partial files); one unrelated syllabus was excluded. There are 61 complete documents: 59 substantive sources and two background sources. The appendix retains 33 executed paired query configurations, 29 supplementary expressions, selection/appraisal methods, the fixed MASS-GT reference, amendments and three remaining priority requests. Neither the queries nor selection decisions changed during this refactor; exhaustive or independent duplicate screening is not claimed.

`results/synthesis-framework.json` describes the framework and historical query identifiers. `results/source-function-map.csv` indexes references cited within each functional section; regenerate it with `python analysis/build-synthesis-map.py` after editing the narrative. It records narrative use, not an independent rereading or retrieval route. Those routes remain in `results/source-search-map.csv` and `references/review-evidence.json`. Imported `domains` metadata denotes historical A1–A7 search topics, not functional numbers.

Other portable evidence: `references/institutional-review.json`, `references/access-pending.json`, `results/review-selection.csv`, `results/review-searches.json` and `results/review-supplements.json`. Source PDFs and the full audit remain outside Git; institutional PDFs are not redistributed. The generator `analysis/import-review.py` preserves the updated appendix narrative while importing historical evidence.

Build: `make check`; checked artifact: `dist/netsy-slr.pdf`. Normal builds require no API, reading-library access or package downloads. Release v0.2.0 fixes the functional synthesis framework. Published v0.1.0 remains immutable; its evidence cohort is unchanged.
